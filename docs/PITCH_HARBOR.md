# Lantern Harbor — Portfolio Pitch

**One-liner:** Cozy coastal conveyor match-3 — sort glowing cargo on the harbor belt, restore moonlit docks, collect endless keepsakes. Sibling product to Crystalline on the same engine.

## Play

| Entry | How |
|-------|-----|
| Local | `npm run dev` → open `/harbor.html` |
| Query | `/?game=harbor` |
| Crystalline (default) | `/` or `index.html` |

Mobile-first portrait (720×1280). Tap once for audio.

## Product pillars

1. **Conveyor Match-3** — shared engine; belt chrome from level 11+ (Sort-inspired row shift)
2. **Harbor Docks meta** — Tideglass → furnish Pier Lights → Market Row → Lighthouse Yard → Night Festival
3. **Live-ops** — Keepsake Album (endless), Tide Rush hybrid event, daily dock run
4. **Cozy idle** — offline Tideglass drip from furnishings (claim anytime)
5. **Ethical shop (simulated)** — 7d/30d ad passes, Comfort Tools, no real charges
